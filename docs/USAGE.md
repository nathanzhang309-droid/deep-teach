# 使用指南

## 使用

1. **⌘O 导入**：PDF、PPT/PPTX、EPUB、Markdown、TXT、HTML。公开文章网址用 **⌘L**。PPT 经本机 Keynote 转成 PDF；首次可能需要允许自动化。
2. **阅读与批注**：选中文字按 **⌘⇧H**，或点击划线按钮。在右侧写笔记、标签，输入立即保存。三种阅读主题、搜索、进度和归档沿用拾页。
3. **问老师**：选中文字后点“问老师”。PDF 的框图按钮开启后深色高亮；框住公式、图表或扫描段落后，选框持续轻微闪动并跟随缩放，聊天栏自动展开聚焦。输入想问的问题，或一键“讲解所选区域”；可重新框选、取消，Esc 退出框选。系统开启减弱动态效果时选框保持静止；没有选区时讲当前页／文章。
4. **追问**：在老师面板输入问题，⌘Enter 发送。右上角设置可选 Codex / Claude、基础水平。支持公式、可点击测验、图表等展示。
5. **收进笔记**：老师回答下点击“收进笔记”，它会和对应页／选区一起进入批注。原有阅读批注与 AI 讲解统一保存。
6. **Obsidian**：在设置中选择自己的库并决定是否自动同步，也可按 ⌘S。右侧“批注”返回笔记，“老师”工具栏按钮打开老师，不会立即发送问题。

7. **调整布局**：拖动书房与阅读区、阅读区与右栏之间的分隔线调整宽度；鼠标移上去会变绿。双击分隔线恢复该栏默认比例，菜单“窗口 → 恢复默认布局”恢复全部比例。老师和批注分别记住比例，重开仍保留；拖窗口边缘可调整整体大小。分隔线获得键盘焦点后，用左右方向键微调，也支持 VoiceOver。

8. **自动学习笔记**：右侧切到“学习笔记”。每次老师完整回答后，本地保存原问答，再用当前订阅后台整理知识点；相同知识点的追问合并并标“重点追问”。可关闭自动整理，手动重试或导入历史问答。重复提问代表关注度，不据此判断学生掌握程度。
9. **大屏复习**：点“大屏复习”打开独立可缩放窗口。可搜索、只看重点追问、回到原页、勾选“我已掌握”、写自己的补充，导出 Markdown 或同步 Obsidian。“学习完成”由学生主动标记。
10. **老师直接红笔批注**：新回答完成后，老师会自动在提问时的课件页圈注、划线、画箭头和写短注，不需要点击贴入；透明文字尽量避开可识别原文。聊天底部可“撤销批注”，也可进入课件编辑修改对象；中途切换文档不会标到另一份课件。全文讲解和复杂图示保留在聊天，图示贴入／另加页仍可手动使用。

10a. **课件批注编辑**：PDF/PPT 阅读工具栏点笔形图标。添加文字、箭头、矩形、圆圈或图片，直接拖动对象、右下角缩放，也可在右侧改文字、字号、颜色、尺寸和位置；支持撤销、重做、删除，自动保存。
11. **讲解贴回课件**：老师回答中的独立公式、图表和图示下点击“贴到当前页”或“另加讲解页”。捕获当前图示为静态图片，默认放在本页右下区域，可移动缩放；仍可回老师面板调整互动图参数后重新贴入。学习笔记中的“加入讲解页”会生成可逐卡编辑的知识点卡片页。
12. **精细学科图示**：老师支持数学逐步推导（算式＋理由＋结论）、Lewis 结构（键、孤电子对、电荷、电子计数），以及生物概念关系图。Lewis 图本地核对电子守恒和形式电荷，错误结构会提示重新生成；不声称自动验证所有分子的化学合理性。长图新增页面时自动增加页高。老师的这套可视化规则为应用内适配，不依赖聊天窗口的可视化工具。
13. **导出批注 PDF**：课件批注侧栏底部点击“导出含批注的 PDF”。包含原页、划线、文字、图形、图片以及页尾新增讲解页。PPT 先转为阅读 PDF，编辑叠加层；不会修改 PPT 内部对象。导出将叠加层固化，适合阅读与分享；继续编辑请回伴读中的原课件。

框图只捕获当前 PDF 中可见的选区；选区图片和整页截图帮助模型看图，不需要单独安装 OCR。模型讲解仍可能出错，保留课件页码方便核对。

## 数据与迁移

新的统一资料库：`~/Library/Application Support/BanduLibrary/`。

- 第一次启动复制拾页资料库，保留文档 ID、划线、手写笔记和同步映射；原 `Shiye/` 目录不动。
- 通过 ⌘O 导入旧伴读 `.bandu` 备份，将 PDF、阅读页码、文字笔记和历史对话迁入书房。按内容识别同一 PDF，重复导入不重复生成记录；原始完整备份留在资料库的“迁移备份”。旧版图片附件保留在原备份，历史图片不会自动转成新的框选高亮。
- 旧伴读使用的 WebKit 学习记录没有删除，旧应用也保留了备份。以后使用新版继续学习；两个旧应用和新版不会持续双向同步各自资料库。
- 栏宽比例独立保存在资料库的 `layout.json`；主窗口大小与位置由 macOS 窗口偏好保存。
- 学习笔记在 `study-notes.json`；课件编辑在 `slide-edits.json`，图片在 `slide-assets/`，原 PDF 保留。JSON 另有前次有效备份；所有内容纳入整库备份。
- 新版的讲解记录在 `teaching.json`，原文和批注在 `documents/` 与 `library.json`；均有上次有效保存备份。通过“文件 → 导出资料库备份”备份全部资料。

## Obsidian

新安装使用 `Bandu/`；已有安装保留原来的同步子目录和 `shiye://` 原文链接。链接会打开新的伴读。

每篇文档一个 Markdown 文件，包含引文、笔记、标签、PDF 页码和返回原文链接。自动生成区域之外的“我的笔记”会保留；你改了自动生成区域时，新版会另存“待合并”，不覆盖手写修改。旧副本在 `.shiye-backups`。

这是 **伴读 → Obsidian** 的单向文件同步，不把 Obsidian 编辑自动回写 App，也不提供自己的跨设备云服务。

## 本地与网络

阅读与笔记可以离线使用。你点问老师／发送问题时，会将相关选区、PDF 当前页图片、附近文字、课程提要、相关笔记与最近对话发送给所选订阅模型。开启“自动整理”后，完成的问答、相关原文与已有知识点会通过同一订阅后台整理；不额外收费 API，但消耗订阅额度。关闭后仅保存原问答；已有历史对话需主动导入才整理。界面的图示截图与 PDF 导出在本机完成。网页导入会访问该网页及图片。模型引擎明确排除 API Key，未登录时提示登录，不偷偷切换付费 API。

老师的子进程限制为只输出教学内容，禁用工具、命令、外部搜索与 MCP；退出 App 或点击停止会中止生成。

## 当前边界

- PDF 划线需要文字层；扫描页可以框图问老师，但没有独立的离线 OCR。
- EPUB 连续阅读，暂不支持 DRM 与章节目录跳转。
- 登录／付费／动态网页不保证提取成功，可自行保存 PDF 再导入。
- 原始 PDF/PPT 不被改写。新增文字与图形可编辑；公式与图表快照是图片，不支持修改其中公式语法或图表数据。新增页追加在页尾。
- Keynote 转换的复杂布局与旧 `.ppt` 不保证完全一致；必要时在 PowerPoint 导出 PDF。
- App 本机签名，未 Apple 公证；没有 Intel 构建。

## 语言

设置顶部可选跟随系统、中文或 English。切换即时生效，不翻译已有笔记，也不清空草稿。若需与界面不同的回答语言，在问题里明确提出；自动整理的新笔记使用当前界面语言。
