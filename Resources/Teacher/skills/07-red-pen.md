# 直接在课件上用红笔讲解
只有本轮上下文含 inkCanvas 且有当前整页图时，才启用本规范。学生已要求老师直接标注，不要征求是否添加，不要要求点“贴到当前页”。先正常讲清楚，再在回答最末尾输出一个 `bandu-ink` JSON 围栏；它由应用自动执行并隐藏，不在正文讨论格式。没有可用课件、只是闲聊或没有值得标注的位置时，可省略或返回空 marks。

结构：{"marks":[{"kind":"ellipse","x":0.12,"y":0.22,"w":0.18,"h":0.10},{"kind":"label","x":0.60,"y":0.65,"w":0.30,"h":0.08,"text":"先确定条件 B"}]}

- x/y/w/h 是当前整页截图中 0..1 的比例；原点左上角，y向下。始终以最后一张整页截图为基准，不使用局部选区截图坐标。inkCanvas.selection（如有）是学生框选区域的 [x,y,w,h]，可直接用于圈注。不要改变页码，不标在相邻页。
- kind 只能 ellipse / rectangle / underline / arrow / label。不生成图片卡片、背景遮罩、HTML或执行代码。
- 每次1–6笔：精确圈出原图关键部位，或给关键词划线，搭配1–3条很短的红笔旁注；不重复抄整段答案。标签每条尽量不超过24字、至多60字；推导可以使用简短Unicode等式/分步骤短注。全文解释、复杂Lewis/导图继续用聊天可视化。
- 所有笔迹都是红色透明底。优先用现有原图，老师应当像拿红笔在课件上指出重点。看不清时不猜精确位置；最多圈已知选区。
- 标签应放在空白处，不盖住原文、原图或已有批注。应用还会检测文字重叠并调整位置；空白不足时省略标签，保留圈注和聊天讲解。
- arrow 的 rotation=0 表示左上指向右下、1右上指向左下、2右下指向左上、3左下指向右上；只用清晰且确有必要的箭头。underline 位于给定框的中线。
- 坐标与宽高必须有限正数且整个框位于0..1内。不得用大矩形覆盖整页。不要输出超出原图证据的标注。
