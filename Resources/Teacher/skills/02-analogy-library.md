# 万能类比库

用前先确认用户熟悉类比对象；一个概念最多一个类比；说完共同点必须说清「不同的是……」。

## 计算机

| 概念 | 类比 | 讲解要点 |
|---|---|---|
| 算法 | 菜谱 | 步骤、输入输出；不同菜谱能做同一道菜 |
| 数据结构 | 衣柜 / 书架 / 抽屉 | 不同收纳方式适合不同场景 |
| 缓存 | 冰箱 | 常用的先放进去，用完再补充 |
| 并发 | 多车道公路 | 多车同行，红绿灯（锁）协调 |
| 递归 | 俄罗斯套娃 | 打开一个里面还有一个，直到最小的 |
| API | 餐厅服务员 | 你点菜，他去厨房（服务器）取，你不用进厨房 |
| Docker | 集装箱 | 里面装什么都不影响外面尺寸统一 |
| 微服务 | 专卖店 vs 百货商场 | 每个服务专注一件事、独立运营 |
| 回调函数 | 留电话等回电 | 你先走，办好了打电话通知你 |
| Git | 游戏存档 | 随时存档，可以回档到任意存档点 |
| 编译器 | 翻译官 | 把你的话翻译成机器能懂的话 |
| 数据库索引 | 书的目录 | 没目录要一页页翻，有目录直接翻页码 |

## 数学

| 概念 | 类比 | 讲解要点 |
|---|---|---|
| 函数 | 自动售货机 | 投什么币出什么饮料，同一个输入永远同一个输出 |
| 导数 | 车速表 | 某一瞬间的变化快慢 |
| 积分 | 给速度曲线算总路程 | 把无数小段加起来 |
| 极限 | 无限靠近但不碰到 | 每步走剩下距离的一半，永远到不了墙 |
| 向量 | 有方向有长短的箭头 | 往东走 3 步 |
| 矩阵 | 一次处理一批数的机器 | 打包的表格 |
| 概率 | 长期频率 | 抛硬币一万次，正面约一半 |
| 对数 | 翻倍次数 | 地震每级能量差 10 倍，用对数压成 1 |
| 虚数 i | 旋转 90° 的指令 | 转两次就是掉头（-1） |

## 物理

| 概念 | 类比 | 讲解要点 |
|---|---|---|
| 电压 | 水压 | 有高低差水才流 |
| 电流 | 水流量 | 每秒流过多少水 |
| 电阻 | 水管粗细 | 越细越难流 |
| 电容 | 水桶 | 先存后放 |
| 电感 | 水流惯性 | 突然关闸，水还想往前冲 |
| 熵 | 房间的凌乱度 | 不收拾只会更乱 |
| 波 | 看台上的人浪 | 人没动，浪传过去了 |
| 量子叠加 | 空中旋转的硬币 | 落下前正反同时存在 |
| 场 | 每点都标了数值的地图 | 温度图、风向图 |

## 化学 / 生物

| 概念 | 类比 | 讲解要点 |
|---|---|---|
| 原子 / 分子 | 乐高积木块 / 拼好的造型 | 化学键 = 积木卡扣 |
| 催化剂 | 媒人 | 自己不参与，让反应更快发生 |
| pH | 酸碱度计 | 越小越酸，7 是中性 |
| 细胞 | 工厂 | 细胞核 = 厂长办公室（DNA = 图纸）、线粒体 = 发电厂、细胞膜 = 门卫 |
| DNA / 基因 | 说明书 / 其中一页 | 照图纸造生命 |
| 免疫系统 | 安保系统 | 抗体 = 通缉令，T 细胞 = 巡逻警察 |
| 神经信号 | 多米诺骨牌 | 一个推一个传下去 |
| 酶 | 钥匙和锁 | 形状对得上才工作 |

## 经济 / 社会

| 概念 | 类比 | 讲解要点 |
|---|---|---|
| 通货膨胀 | 钱变毛了 | 同样的钱买的东西变少 |
| 复利 | 滚雪球 | 利息再生利息，越滚越大 |
| 供需 | 菜市场 | 人多菜少就涨价 |
| 机会成本 | 选了 A 就放弃了 B | 鱼与熊掌 |
| 保险 | 大家凑份子 | 谁出事帮谁 |
| GDP | 全家一年总共挣多少 | 只算新产出 |

## 语言学习

| 概念 | 类比 | 讲解要点 |
|---|---|---|
| 语法 | 游戏规则 | 词是棋子，语法是走法 |
| 时态 | 时间轴上的标记 | 站在哪一段说话 |
| 语感 | 骑车的手感 | 规则忘了但身体记得 |
